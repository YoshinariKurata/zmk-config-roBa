roBa キーマップ（Mac 版）

YoshinariKurata/zmk-config-roBa の config/roBa.keymap をそのまま図にしたものです。左が左手側、右がトラックボールのある右手側です。

モード

キーにカーソルを合わせる（スマホではタップする）と、ここに詳しい説明が出ます。

  • タップで入力
  • オレンジの小さい文字 = 長押ししたときの動き
  • このレイヤーに入るために押したままにするキー
  • 空欄 = 基本レイヤーと同じキー
  • 「なし」= 何も入力されないキー
キーを押すと「L0 のこの場所」という説明をコピーします。そのままチャットに貼り付けて変更を頼めます。

同時押し（コンボ）

  • /K→英数
  • /T→かな
  • -Tab→Shift + Tab
  • ':→今のレイヤーのキーマップ図を表示（Mac・Hammerspoon）。Windows モードでは Ctrl+Alt+F13 を送り、Windows 側のスクリプトが図を画面の上端に重ねます（もう一度押すと消えます）

覚えておくこと

  • 長押しは 0.2 秒以上。短く押すとタップ側が入力されます。
  • 左親指・右のキー: 1回押しで基本へ戻る（どのレイヤーからでも）、2回押しで数字レイヤー。長押ししている間は Z の位置が Shift（仮置き）。
  • かな / 英数は / と T / K の同時押し、Tab は左手・上から2段目の一番内側、⇧Tab は - と Tab の同時押し。
  • 左親指・左のキーを押しながら T で !、N で ?、K で「」、S で（）、W で『』、R で［］、Y で【】、H で …。括弧はペアで入力されてカーソルが中に入ります（Mac・Hammerspoon。入力中はクリップボードを一瞬使います）。
  • . を1秒押し続けると設定・BT。合図は出ないので、1秒待ってから右手で接続先を押します。
  • 右親指・左のキーが ⌫。
  • トラックボールを動かすとマウスレイヤーに入り、R / Y / P がクリックになります（Y 長押しでスクロール）。左親指・右のキーを1回押すと元に戻ります。戻さなければ 10 分間そのままで、その間は文字を打てません。数字レイヤー中にボールを動かしたときも同じです。
  • マウスレイヤー中の Q はタップで今のウィンドウを閉じる（⌘W）、長押しで全部閉じる（⌥⌘W）。
  • マウスレイヤーの左手: L で最小化（長押しでフルスクリーン）、U / I / A / O が矢印キーの形で、U（上）が Mission Control、I / O（左右）がデスクトップ移動、A（下）がアプリのウィンドウ一覧。E がすべて選択、X / C / V がカット / コピー / 貼り付け、, の位置で通知を消す、左手・上から2段目の一番内側でスクリーンショット。右手の F の位置で Finder、N / H で前 / 次のタブ。
  • スクロールはマウスレイヤーの Y を押したままトラックボールを転がします。Y を押している間は数字の位置が F キーになるので、R の左クリックは F8 になります。
  • F キー: 数字レイヤーで L の位置を押し、次に数字。0 の位置で F10、1 の2回押しで F11、1 と 2 の同時押しで F12。F1 は少し遅れて入力されます。
  • ' のキーは長押しで "。
  • ロータリーエンコーダ（左手側）は PgUp / PgDn。左親指・右のキーを押している間は ⌃PgUp / ⌃PgDn です。
  • かな・英数は Mac の日本語入力（ローマ字入力）が入っていると動きます。キーボードの種類は ANSI にしてください。
  • モードは接続先を切り替えるキーで決まります。. を1秒押したまま F で Mac（MacBook）、W で Windows、R で Android（どちらも Windows・Android モード）。Y（接続先4）と P（接続先5）は未使用。電源を入れ直すと Mac モードに戻るので、接続先 2・3 のときはもう一度 W / R を押してください。
  • Windows・Android モードの英数/かなは無変換/変換を送ります。Windows では Microsoft IME の設定で「無変換＝IME オフ、変換＝IME オン」にしてください。
